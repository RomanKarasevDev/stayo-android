# Changelog

## 0.1.0 (unpublished)

- Kotlin coroutine API for Auth/PKCE, database/RPC, files, functions and Realtime.
- Project/account-scoped Android Keystore session adapter and refresh barriers.
- Database, RPC and Storage responses that arrive after sign-out or an account
  switch fail with `auth_superseded`; no request is retried.
- Email/code confirmation and recovery; bounded nested Functions error codes.
- INSERT/UPDATE subscriptions with explicit snapshot resynchronization.
- Local Maven AAR, sources and documentation artifacts; shared UUID notes sample.

Real OAuth and device/Keystore acceptance remain open. Maven Central ownership,
publisher signatures and publication require a separate approved release.
